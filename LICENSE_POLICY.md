# License and Source Reuse Policy

Do not copy implementation code from another SZL repository merely because it is
in the same organization. Before reuse:

1. verify repository and file-level license;
2. preserve required copyright/NOTICE material;
3. record exact source revision and path;
4. prefer a versioned dependency or adapter over copied files;
5. document modifications;
6. do not import code whose third-party origin or license is unclear;
7. do not remove attribution from research-inspired implementations.

The project license must be selected and reviewed by SZL before publication.
