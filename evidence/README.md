# Evidence

Only generated observations belong here. Every record should include:

- source revision and dirty-state status;
- tool/runtime versions;
- platform identity;
- exact command;
- start/end timestamp;
- input/package/bitstream/firmware digests;
- raw result and limitations;
- receipt or signature scope;
- `SOFTWARE_EMULATED`, `FPGA_MEASURED`, `BLOCKED`, or `UNAVAILABLE` label.

Do not hand-edit measured outputs. Preserve failed runs rather than replacing
them with a green summary.
