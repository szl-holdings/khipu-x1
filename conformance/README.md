# Conformance

The `tests/` directory is the initial software-reference suite. Expand with:

- JSON and future binary descriptor golden vectors;
- PyTorch/NumPy differential vectors;
- quantization calibration records;
- archive parser fuzz corpus;
- RC1 protocol fuzz and replay/expiry cases;
- RTL simulator vectors;
- reset/brownout/timeout/fault cases;
- exact hardware/bitstream matrix;
- deterministic build and source-lock verification;
- benchmark receipts with raw measurements.
