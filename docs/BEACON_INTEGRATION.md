# A11oy Beacon + KHIPU-X1 Integration

KHIPU-X1 is an optional acceleration organ, not the safety authority. Beacon must
remain operable without it.

```text
Local UI / A11oy bounded agent
          |
          v
  proposal + evidence
          |
          v
human/policy authorization
          |
          +----> KHIPU-X1 inference receipt (optional acceleration)
          |
          v
       RC1 boundary
          |
          v
 low-voltage bench actuator
          |
          v
independent witness input
          |
          v
Outcome Receipt or open Reality Debt
```

## First demonstration

- offline browser interface;
- one structured need or equipment-alert record;
- machine proposal visibly labeled inference;
- explicit human approval;
- RC1 emulator/hardware accepts one authenticated low-voltage action;
- separate switch/sensor reports observed state;
- missing/conflicting witness prevents `OUTCOME_VERIFIED`;
- receipt export verifies on another offline computer;
- no medical, vehicle, access-control, high-energy or life-safety actuation.
