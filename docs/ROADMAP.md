# KHIPU-X1 Evidence-Gated Roadmap

Planning ranges are not delivery commitments.

## M0 — Estate audit and source lock

Output repository inventory, exact revisions, code/licensing map, duplication
report and chip-readiness matrix.

## M1 — Software-reference contract

KIDS v0.1, deterministic simulator, receipt chain, graph lowering, package
format, RC1 emulator and conformance suite.

## M2 — Tiny transformer path

Add quantization calibration, RoPE, causal attention reference, KV-cache
reference, tokenizer/sampling and an end-to-end tiny decoder test.

## M3 — FPGA development-board proof

Select FPGA, implement descriptor queue, DMA/test path, INT8 compute,
normalization and SHA3 receipt block. Differential-test exact outputs and report
measured timing/resources/power.

## M4 — One custom carrier/appliance prototype

Minewing or disclosed partners integrate FPGA/SOM, memory, RC1, secure element,
power telemetry, communications, cooling, enclosure and Beacon I/O.

## M5 — ASIC feasibility only

Create architecture exploration, workload/business case, node/IP assumptions,
verification plan, cost/risk range and partner shortlist. No tapeout without
funding and evidence-gate approval.
